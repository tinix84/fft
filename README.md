# fft

Python FFT utilities for power electronics waveform analysis.

## Features

- FFT and spectral analysis functions tailored for power electronics
- Harmonic extraction and THD calculation
- Support for time-domain waveforms from simulation and measurement tools
- MATLAB equivalent functions in `mfiles/`

## Installation

```bash
pip install -e .
```

## Contents

| Path | Description |
|:-----|:------------|
| `fft/` | Python package — FFT functions and helpers |
| `mfiles/` | MATLAB equivalent implementations |
| `tests/` | Unit tests |

## Requirements

- Python 3.x
- NumPy, SciPy, Matplotlib
